# Currículo — Jonathan Oldoni

Currículo online de especialista automotivo, feito com **HTML5** e **CSS3**.

## O que tem

- Seções de apresentação, experiência, habilidades e certificações
- Telefone e e-mail clicáveis (abrem a ligação e o app de e-mail)
- Layout responsivo para celular
- Versão para impressão: no navegador, use **Imprimir → Salvar como PDF** para gerar o currículo em PDF

## Como abrir

Abra o `index.html` no navegador ou use a extensão **Live Server** do VS Code.

## Tecnologias

- HTML5 semântico
- CSS3 com variáveis, Flexbox e media queries
- [Font Awesome](https://fontawesome.com/) para os ícones
